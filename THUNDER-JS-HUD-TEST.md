# Thunder JS HUD test

This file is a test launcher for the JavaScript 1.12 runtime.

It uses the existing Thunder `classes.js` (including the native HUD + Right Shift code) and expects:
- `assets.epk`
- `lang/en_us.lang`

`index.html` is intentionally unchanged in this stage.

Before switching the live launcher, add the matching `assets.epk` from the clean Eaglercraft 1.12 JS build.
